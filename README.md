
# SmartLearn 🎓

## About

SmartLearn is a modern Learning Management Platform built with React.

It helps students access courses, study online, take quizzes and track their learning progress.

## Features

- Student dashboard
- Home page
- Course section
- Quiz section
- Certificates
- Learning progress
- Admin dashboard (planned)
- Dark modern design
- Responsive layout

## Technologies

- HTML5
- CSS3
- JavaScript
- React
- Vite
- React Router
- Lucide React

## Installation

Clone the project:

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

Open the project:

```bash
cd smartlearn
```

Install packages:

```bash
npm install
```

Run the project:

```bash
npm run dev
```
